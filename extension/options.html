YouTube quick start

Refresh a selected broker profile from an interactive browser session

  1. Open chrome://extensions, select Details, and enable Allow in incognito for this extension.
  2. Save the broker connection and dedicated publisher credential below.
  3. From the status popup in a regular window, select Refresh session for a YouTube profile.
  4. Close every other incognito window, then sign in interactively in the broker-created window. The extension continues to youtube.com/robots.txt.
  5. With isolation enabled, only the broker-created incognito window closes after a successful publish.

Only youtube.com cookies are captured for YouTube. Google login navigation is not part of the exported cookie scope.
